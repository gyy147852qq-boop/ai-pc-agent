# AI 电脑代理（AI PC Agent）

把网页端 AI 聊天机器人（DeepSeek / ChatGPT / Kimi…）变成你 Windows 电脑的 Agent。

> 🔗 https://github.com/gyy147852qq-boop/ai-pc-agent ｜ MIT License ｜ Node.js 22+，零第三方依赖

你不用复制粘贴，它自己跑：

```
你写需求  →  软件把「电脑状态 + 需求 + 操作协议」发给网页 AI
         →  AI 回复里带 ```powershell 代码块
         →  软件提取代码、判风险、（必要时问你）在本机执行
         →  把执行结果回传给 AI
         →  AI 给下一步 …… 直到它说 DONE
```

零第三方依赖，不用装 Python，不用 API Key，用的就是你自己登录的网页版。

---

## 三种桥接方式

| 方式 | 原理 | 优点 | 缺点 |
|---|---|---|---|
| **油猴脚本**（推荐） | 装一个 Tampermonkey 脚本，它在你已打开的聊天页里收发消息 | 最稳，用已登录的网页，不碰浏览器进程 | 要装一次浏览器扩展 |
| **浏览器接管** | 用 CDP 协议直接驱动一个 Edge/Chrome 窗口，自动打字、点发送、读回复 | 不用装插件 | 网页大改版时选择器可能失效 |
| **手动复制粘贴** | 软件把要发的内容显示出来，你自己粘 | 应急、调试用 | 每轮都要手动 |

三种都在面板里一键切换，互不影响。

## 快速开始（油猴方式，3 分钟）

1. **启动软件**：双击 `start.bat`
   （会用 Edge 的「应用窗口」模式打开面板，看起来就是个独立软件；端口 8787）
2. **装桥接脚本**：面板右侧「接入步骤」里点「点这里安装桥接脚本」→ Tampermonkey 会弹安装页 → 安装
   （没装 Tampermonkey 的话先装：Edge/Chrome 扩展商店搜 Tampermonkey）
3. **打开聊天页**：https://chat.deepseek.com 并登录
   页面右下角会出现一个小胶囊：`AI 代理：已连接`
4. **回面板**：右边写需求 → 点「开始」

想换浏览器接管方式：设置里把「桥接方式」改成「浏览器接管」→ 保存 → 点「重连浏览器」→ 在弹出的窗口里登录一次 DeepSeek → 再点一次「重连浏览器」。

## 更省事的接入：一键接管浏览器（不用装扩展）

面板右侧「接入步骤」→ 点 **「一键接管浏览器」**：

1. 软件自动开一个 Edge 窗口（独立配置目录，跟你平时的 Edge 互不影响）
2. 在那个窗口里**登录一次 DeepSeek**（手机号收验证码 / 密码都行）
3. 回面板再点一次（按钮会变成「重新检查」）
4. 顶栏变绿显示「浏览器接管 已连接」→ 可以用了

之后每次启动都会直接接管这个窗口，登录状态是记住的，不用再登。

> 如果那个窗口停在登录页，面板会直接告诉你「浏览器停在 DeepSeek 登录页」，
> 而不是含糊的「找不到输入框」。

## 桌面快捷方式

双击 `创建桌面快捷方式.vbs`，一次就好。桌面上会出现一个带图标的「AI 电脑代理」，
双击它启动——**不会弹黑窗口**（后台静默启动，然后直接出面板窗口）。

关软件用面板右上角的「退出」按钮，不要用任务管理器。

把整个文件夹搬到别处、或改了端口之后，**重新双击一次这个脚本**就会覆盖成新的。

> 为什么给的是一个脚本而不是现成的 `.lnk`：
> Win11 的快捷方式必须内嵌目标 IDList（含卷 GUID、时间戳），手工拼的 .lnk 会变成
> 「打不开的坏图标」。脚本走系统 Shell 接口生成，保证合法。
>
> 不想用脚本也行：右键 `start.bat` → 发送到 → 桌面快捷方式（图标是默认的 bat 图标，
> 而且会留一个黑窗口）。

相关文件：

- `launch.vbs` —— 无窗口启动器（隐藏启动 + 健康检查，起不来会弹提示）
- `assets/icon.ico` —— 软件图标（16/24/32/48/64/128/256 七种尺寸，`node tools/make-icon.js` 可重新生成）
- `data/server.log` —— 后台日志，出问题时看这个

## 打包分发

```bash
node tools/pack.js "AI电脑代理"
```

会在**上一级目录**生成一个干净的包（`AI电脑代理/`），并自动带上 `首次使用.txt`。

打包时剔除：运行时垃圾（`data/` 里两个 Edge 配置目录约 1GB）、日志、`.lnk` 快捷方式。
保留：源码、面板、图标、启动脚本、测试、工具。成品约 200 KB / 27 个文件。

安全护栏：目标目录已存在且**不像**本脚本生成的包时拒绝覆盖（判据是
`server.js` + `package.json` + `首次使用.txt` 三个特征文件同时存在）。

> `ai-pc-agent/` 是**开发目录**（有你的浏览器登录态、体积大）；
> `AI电脑代理/` 是**分发包**（干净、但第一次用要重新登录一次 DeepSeek）。

左边是执行过程，每张卡片代表一步：

- 蓝边 `我的需求` —— 你输入的目标
- 紫边 `网页 AI` —— AI 的原始回复
- 深色 `执行命令` —— 提取到的 PowerShell，右上角标风险等级（只读 / 写操作 / 高危）
- 灰底 `输出` —— 真实执行结果，带退出码和耗时
- 黄边 `需要你确认` —— 写操作在等你点「允许 / 拒绝」
- 绿边 `完成` —— AI 说 DONE 了

右边是控制台：需求输入、待确认命令、AI 的提问、设置、接入步骤。

## 安全设计

这套东西能让网页 AI 在你电脑上执行代码，所以安全边界是重点：

1. **只读自动，写操作确认**（默认）
   风险分三级：`Get-*` / `dir` / `Test-Path` 这类只读命令直接跑；
   删除、新建、改注册表、装软件 → 停下来等你点允许；
   格式化、分区、关机、删系统目录、`iwr | iex` 这类 → 标红高危，必须你点。

2. **只监听 127.0.0.1**
   外网访问不到；面板接口还要求 token + 同源，别的网页没法偷偷驱动它。

3. **桥接脚本只连本机**
   油猴脚本里 `@connect 127.0.0.1`，不往任何外部服务器发数据。

4. **输出截断**
   单条命令输出超过 9000 字符会掐头去尾，防止把上下文撑爆。

5. **可随时停止**
   「停止」会杀掉正在跑的 PowerShell 进程树。

> 提醒：AI 会犯错，也可能理解偏。**涉及删文件、改系统设置时，务必看一眼命令再点允许。**
> 高危规则是黑名单式的，不可能穷尽；它的作用是「拦住明显的坑」，不是「保证绝对安全」。

## 它和「给 AI 一个 API Key」有什么区别

- **好处**：不花钱、不用申请 Key、直接吃网页版的最新模型和联网能力
- **代价**：依赖网页 DOM。DeepSeek 改版可能让选择器失效 —— 这时改 `lib/page-agent.src.js` 里 `PROFILES` 的 `assistant` / `composer` 选择器即可，逻辑不用动
- **上下文**：靠网页对话本身的记忆，所以**别在任务中途开新对话或清空历史**，否则 AI 会忘记目标

## 常见问题

**页面右下角没有小胶囊？**
脚本没生效。检查：Tampermonkey 里脚本是否启用；页面是否在 `@match` 列表里（DeepSeek / ChatGPT / Kimi / 豆包 / 通义，别的站点自己加一行 `@match`）；刷新页面。

**显示「已连接」但点了开始没反应？**
看面板左边有没有报错。如果是「等待网页 AI 回复超时」，通常是 AI 那边卡在登录页或限流了。

**AI 老是不按协议输出代码块？**
换一个更听话的模型，或在需求里加一句「请严格按协议，一次只给一个 powershell 代码块」。

**命令执行成功但 AI 说失败了？**
有些命令（比如启动 GUI 程序）没有 stdout，AI 会误判。可以在需求里让它用 `Test-Path` / `Get-Process` 验证结果。

**端口 8787 被占用？**
改 `data/config.json` 里的 `port`，重启。桥接脚本会跟着新端口重新生成。

**想支持别的网页 AI？**
1. `lib/userscript.tpl.js` 顶部加 `// @match https://你的站点/*`
2. `lib/page-agent.src.js` 的 `PROFILES` 里加一条，写上回答容器和输入框的选择器
3. 重新安装脚本（面板里点安装链接覆盖）

## 已验证 / 未验证

**自动化测试**：`selftest.js` 36 项、`e2e.js` 30 项、`cdp-test.js` 8 项，全绿。

**真实环境端到端已验证**（DeepSeek 网页版，浏览器接管模式）：

| 任务 | 结果 |
|---|---|
| 看看 C 盘还剩多少空间 | ✓ 2 轮，真实读出「剩余 47.90 GB / 共 300.01 GB」 |
| 在临时目录建文件夹并确认 | ✓ 3 轮，`New-Item` 弹确认 → 同意 → 执行 → 验证 → DONE |

DeepSeek 页面的实际结构（踩过的坑，记在这免得以后重踩）：

- 输入框是真 `<textarea>`（`textarea#chat-input`）
- **页面上没有任何发送按钮**（无 button / role=button），发送只能靠回车
- 直接改 `textarea.value` **没用**：字进去了，但 React 内部状态没更新，回车被忽略
  → 必须用 CDP 的 `Input.insertText` + `Input.dispatchKeyEvent` 发**真实**输入事件

**油猴路径在 DeepSeek 上未验证**：油猴脚本发不出「可信事件」，合成回车可能被忽略，
加上 DeepSeek 没有可点的发送按钮，这条兜底路线可能走不通。**建议就用浏览器接管**。

排查工具：`GET /api/inspect` 会返回页面体检（URL、输入框类型、附近可点元素），
「找不到输入框 / 发不出去」时先看这个。`node test/live.js "需求"` 可以对着真实 AI 跑一遍并打印全过程。
